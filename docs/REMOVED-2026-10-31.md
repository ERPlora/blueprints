# Imágenes retiradas el 2026-10-31

Dos auditorías visuales independientes de la librería (2026-10-31) encontraron fotos de **productos de
terceros**: marcas y logotipos visibles, envases y etiquetas reconocibles (la «botella contorno» de Coca-Cola,
por ejemplo) y el cartel de un comercio real. Nada de eso se puede publicar con licencia MIT, así que Ioan
decidió retirarlas y sustituirlas más adelante por imágenes generadas.

Se retiran **15 ficheros** (14 dibujos distintos: `hospitality/sprite.webp` era un alias, byte a byte el mismo
fichero que `hospitality/coca_cola.webp`, comprobado con `shasum`), con su entrada de `img/catalog.json`:

| Fichero | Motivo |

| `hospitality/cerveza_sin.webp` | etiqueta comercial de una cerveza, desenfocada pero reconocible |
| `hospitality/coca_cola.webp` | botella contorno de Coca-Cola (envase registrado) |
| `hospitality/coca_cola_zero.webp` | imagen de marca de Coca-Cola Zero (colores y envase) |
| `hospitality/fanta_limon.webp` | logotipo de Fanta |

## Para que no vuelva

- `scripts/catalog.py validate` rechaza un título o un tag que nombre una marca de su lista `BLOCKED_BRANDS`
  (palabra entera, sin distinguir mayúsculas); lo corre la CI en cada PR.
- `README.md`, «Convenciones»: solo iconos planos propios o fotos propias o generadas de productos genéricos;
  ni marcas, ni logotipos, ni envases o etiquetas reconocibles, ni carteles, ni personas reconocibles.

## El bucket

`publish.yml` nunca borra del bucket: tras el merge, los ficheros retirados siguen en
`s3://erplora-<entorno>-hubs/shared/catalog/` hasta la poda explícita:

```bash
gh workflow run publish.yml -R ERPlora/blueprints -f prune=true -f max_prune=20
```

## Sustitutas

Las sustitutas serán **imágenes generadas** (ChatGPT Images, las aporta Ioan) de productos genéricos, sin
marca. Entran como cualquier imagen nueva (`README.md`, «Añadir una imagen») y **con un nombre nuevo**: una
imagen publicada se sirve con caché inmutable de un año, así que un navegador que ya tenga la foto retirada la
seguiría viendo con el mismo nombre. Las semillas del Hub que apuntaban a una imagen retirada
(`catalog:hospitality/coca_cola` para «Refresco» en `base/seeds/restaurant.{en,es}.json` de `ERPlora/hub`) se
cambian en una PR del Hub.
